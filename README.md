# minecraft-2
# що є в грі
-  3D-гра на Java

- логи

- текстури

- інвентар ( за допогою кнопки  H )

- моделька гравця 

- огляд мапи ( не працює виправляємо як найшвидше )

- випаданя блоків 

-  процедурна генерація чанків 16×16

-  генерація рельєфу

-  автоматична генерація світу

-  позиція та рух гравця

-  огляд мишкою

-  ламання блоків

-  встановлення блоків

-  вибір блоків через `1`, `2`, `3`

- зміна часу/освітлення

-  збереження ( за допомогою кнопки J )

-  головне меню

# інкструкція
обов'язково завантажте JDK 17 (або JDK 21) і завантажте .zip перейдіть у app/build/libs і  і редеагуйте run.bat у блокноті вставте шлях до своєї папки замість моєї запустіть run.bat обов'язково відкрийте папку app/build/libs.


-  Fullscreen 1920×1080

- готовий `.jar`

- Windows-версія
